# Rules

## Never publish

This repository is public. Never put any of these in a commit, branch name, commit message, issue, pull request or comment:

- **Video, audio, subtitle or cut list files** from real videos.
- **Details of real videos:** titles, file names, quoted dialogue, timestamps or metadata (such as resolution, frame rate, codecs, duration or size).
- **Sensitive data:** credentials, API keys, tokens, secrets or personal data, including local paths with a user name.

Tests generate their own synthetic media and made-up subtitles. Describe a bug found in a real file in general terms.

Check the staged files and message against this list before every commit.
